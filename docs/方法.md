# 方法：让 Mac 在 AI 时代保持精简

一句话：**一个东西在电脑上只留一份，放在哪看它处在哪个阶段；AI 写文件时就按规矩放好，每周体检只负责发现问题，删不删由你点头，删也只进废纸篓。**

下面是建议，不是标准答案。天数、文件夹名、用哪家备份，照你自己的情况改。

## 1. 四层机制

```
① 规矩（预防）        AI 写文件那一刻就放对地方
② 每周体检（发现）    只读，只列异常
③ 你点头，AI 执行     先查引用，收进一个带日期的文件夹，整个移进废纸篓，记下从哪到哪
④ 兜底               废纸篓 30 天 + 备份
```

最重要的是第一层。AI 放对了，后面就没有要清的。

## 2. 分清两块地盘

| 地盘 | 在哪 | 怎么管 |
|---|---|---|
| 工具的 | `~/.claude`、`~/.codex`、`~/Library/Application Support` 里各 App 的文件夹、`~/Library/Caches` | 不手动删里面的东西（结构随版本变，删错了工具会出错），用 App 自带的清理入口；体检只看它们一周涨了多少 |
| 你的 | 工作区、仓库、App、笔记 | 按阶段放（下一节） |

## 3. 按阶段放：三个文件夹

| 东西 | 放哪 | 多久没动体检会提醒（默认） |
|---|---|---|
| 在做的事 | `工作区/projects/<项目名>/` | 90 天，问你"搬 / 删 / 留" |
| 项目里的过程文件 | 那个项目的 `work/` | 30 天 |
| 做完的成品 | `工作区/outputs/YYYY-MM-DD-主题/` | 90 天，问你它该去哪 |
| 一次性任务的过程文件 | `工作区/scratch/YYYY-MM-DD-主题/` | 30 天 |
| 做好、偶尔维护的仓库 | `~/Documents/GitHub/<仓库名>/`，推到 GitHub | 不按时间清，只报"没推送""有重复" |
| 做好的 App | `/Applications` | — |
| 后台服务要用的程序 | `~/.local/share/<名字>/`（后台服务读不到文稿、桌面、下载） | — |
| 主目录、桌面、下载 | 不散放 | 14 天 |

**项目名由你起。** AI 拿不准一件事算不算项目时，问一句"要不要起个项目名"；不起名就当一次性任务，过程文件进 `scratch/`。AI 自己建项目文件夹，就会越建越多。

**一个东西的一生**：开始做放在 `projects/`；过程中的试验放 `work/`，30 天后清；做好了，代码搬进 `~/Documents/GitHub/` 并推到 GitHub，App 装进「应用程序」，`projects/` 里那份删掉。

## 4. 一件事只写在一个地方

- **规矩**：全局一份（`~/.codex/AGENTS.md`，Claude Code 用 `@` 引用同一份）；某个文件夹有自己的讲究，就在那里放一份只管它自己的。同一条写在好几处，改一处就漏一处。模板见 `templates/AGENTS.md`。
- **skill**：自己写的放一个仓库，各个 skills 文件夹里放链接。存好几份，版本迟早分叉。
- **仓库**：一个仓库只留一份。
- **项目状态**：写在项目的 `README.md` 里（这是什么、做到哪、下一步），换 AI 接手先读它，不另写交接单。

## 5. 四个 AI 工具的文件都在哪

| | 对话存在哪 | 干活的文件落在哪 | 要知道的 |
|---|---|---|---|
| Claude Code | `~/.claude/projects/<打开的文件夹路径>/`，本机 | 你打开的那个文件夹 | 记忆按"打开的文件夹"分开存，换了文件夹就记不住之前的事，所以固定在工作区里打开。终端里开的会话 30 天没动会被自动删掉；Claude App 里的不会（App 可以设置闲置自动归档） |
| Codex | `~/.codex/sessions/`，本机 | 项目的主要文件夹；不选项目时，Codex 自动建 `~/Documents/Codex/<日期>/<对话>/` | 侧边栏的项目按路径认文件夹，文件夹一挪就断。项目可以挂几个文件夹：把工作区设为主要文件夹，它就和 Claude 读同一份规矩 |
| ChatGPT | 云端 | 云端；下载的进「下载」 | 对电脑空间影响最小，主要是下载文件夹 |
| Cowork（Claude App） | App 自己保存 | `~/Claude/Projects/<项目>/` | 它的虚拟机约 10 GB 是固定成本，用 Cowork 就别动；定时任务在 App 的 Scheduled 页 |

**定时任务**散在好几个地方：系统的 `~/Library/LaunchAgents`、Codex 的 `~/.codex/automations/`、Claude Code、Claude App 的 Scheduled 页。一个地方查不到不等于没有。定期跑的任务用"每次新开"的独立任务；挂在一个对话上的，会绑住那个对话的文件夹，只适合临时盯一件事。

## 6. 七道保险：清掉该清的，不误删不该删的

1. **体检只读**：发现和删除分开。
2. **你点头才动**：AI 一次只处理你点名的几项。
3. **只进废纸篓**：AI 不永久删除，不清空废纸篓。
4. **动之前查引用**：AI 工具的项目列表、自动化和 skill 里写死的路径、快捷方式、开机自启、脚本、AI 的记忆、所有规则文件。
5. **每次删都有清单**：收进带日期的文件夹，里面放一份"从哪来"，能原样放回。
6. **凭证永远不打开**：名字像密码、密钥的文件只报名字。
7. **分清"没用"和"用过"**：看最后修改时间，不看创建时间；"很久没改"不等于"没在用"；只有一份、别处没备份的，删之前单独提醒。

## 7. 每周只要 5 分钟

1. 看一眼体检报告。没有要处理的，就结束了。
2. 有要处理的：回一句"1 和 3 清掉"；很久没动的项目回"搬 / 删 / 留"。
3. AI 列出要动什么，你点头。
4. 废纸篓想清就清；打开访达的"30 天后移除废纸篓中的项目"，不清也会自动清。

其余的（放对地方、备份、查后台）都是自动的。

## 8. 备份：敢清理的底气

只备份"没有别的备份"的东西：代码在 GitHub、笔记有自己的同步，就不用重复备份。剩下的（工作区的项目和成品、AI 的规矩、自动化、skill、记忆）每周复制一份到 iCloud 云盘或移动硬盘，模板见 `templates/backup.sh`。

iCloud 只开「iCloud 云盘」就够了。「桌面与文稿」同步和「优化储存空间」要想清楚再开：文稿里有代码仓库和笔记，再叠一层同步容易冲突；文件被挪到云上以后，AI 和后台程序也读不到。
